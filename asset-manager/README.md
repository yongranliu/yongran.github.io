# 持衡 · 个人资产管理

一个纯静态的资产管理看板：收支变化、资产配置、持仓明细，以及主流货币换算。所有数据都是示例数据，用于演示版面与计算逻辑。

- **总览**：净资产曲线、月度收支、资产配置色块、支出结构、最近流水
- **收支分析**：收入来源、支出分类、完整流水（可按收入 / 支出筛选）
- **资产配置**：当前配置与目标比例的偏离、再平衡建议、进取型 / 防御型占比
- **资产明细**：持仓市值、成本、浮动盈亏，盈亏贡献与负债
- **货币换算**：新台币、人民币、港币、美元、欧元、日元、英镑、澳元互换；右上角可切换全站显示币种

汇率是示例参考值，并非实时行情，可在「货币换算」页右侧直接修改。

## 文件

- `index.html`：页面、样式与数据（账目以新台币记录）
- `dc-lite.js`：一个很小的模板运行时，负责 `{{ }}` 绑定、`sc-if` / `sc-for` 与事件，无外部依赖

## 本地预览

```
python3 -m http.server 8000
```

然后打开 http://localhost:8000/asset-manager/ 。

字体通过 Google Fonts 加载（DM Serif Display、Noto Serif SC、Noto Sans SC），离线时会退回系统字体。

## 换成自己的数据

打开 `index.html`，在末尾的脚本里找到 `getData()`，把 `holdings`（持仓）、`income` / `expense`（月度收支）、`txs`（流水）、`liabs`（负债）改成自己的即可。金额一律以新台币填写。

## 更新：时间范围与记账

- 收支分析 / 总览支持 **按日、按周、按月** 查看，并有预设范围（近 7/30/90 天、近 8/12/26 周、近 3/6/12 个月、今年以来）和自定义起止日期；指标会与上一个同长度区间对比。
- 数据改为逐笔流水生成（示例数据），类别与流水随所选区间变化。
- 「记一笔」可新增收入/支出，保存在本机浏览器（localStorage），可随时删除。
